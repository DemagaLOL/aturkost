# Aturkost Backend (Clean NestJS Scaffold)

## Cara Menjalankan
1. Salin `.env.example` menjadi `.env`:
   ```bash
   cp .env.example .env
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Jalankan server dalam mode development:
   ```bash
   npm run start:dev
   ```
Server berjalan di `http://localhost:3001/api`.
